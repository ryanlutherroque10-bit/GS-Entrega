# GS Citizen Assist AI — Data Structures and Algorithms

Repositório da entrega de **Data Structures and Algorithms (DSA)** da Global Solution 2026.2 (Citizen Assist AI).

**Integrantes:** Ryan Luther Roque (RM 572993) e João Guilherme Figueiredo (RM 572697)

O trabalho está na pasta [`06-dsa-python`](06-dsa-python/): um catálogo de serviços ao cidadão, em Python, sobre uma lista simplesmente encadeada implementada pela equipe, com busca linear, Insertion Sort, menu no terminal e persistência em CSV.

## Executar

Requer Python 3.10 ou superior, sem bibliotecas externas.

```sh
cd 06-dsa-python
python main.py
```

## Testar

```sh
cd 06-dsa-python
python -m unittest discover -s testes -v
```
